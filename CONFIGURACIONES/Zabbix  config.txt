Zabbix Agent 2 — configuración Ubuntu
Archivo: /etc/zabbix/zabbix_agent2.conf. Host técnico Ubuntu-ITLA; dirección del agente 192.168.60.23:10050.
Server=127.0.0.1,192.168.60.23
ServerActive=127.0.0.1
Hostname=Ubuntu-ITLA
sudo systemctl enable zabbix-agent2
sudo systemctl restart zabbix-agent2
sudo systemctl status zabbix-agent2
5. Zabbix Server — configuración de base de datos
Archivo: /etc/zabbix/zabbix_server.conf. La contraseña de MariaDB se ha sustituido por un marcador para no publicar credenciales.
DBName=zabbix
DBUser=zabbix
DBPassword=<CONTRASENA_CONFIGURADA>
sudo systemctl enable zabbix-server
sudo systemctl restart zabbix-server
sudo systemctl status zabbix-server
6. MariaDB — creación de base de datos, usuario y permisos
sudo mariadb

CREATE DATABASE zabbix CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
CREATE USER 'zabbix'@'localhost' IDENTIFIED BY '<CONTRASENA_CONFIGURADA>';
GRANT ALL PRIVILEGES ON zabbix.* TO 'zabbix'@'localhost';
SET GLOBAL log_bin_trust_function_creators = 1;
FLUSH PRIVILEGES;
EXIT;
Importación del esquema de Zabbix:
zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | mysql -u zabbix -p zabbix
Verificación de tablas:
sudo mariadb -e "SELECT COUNT(*) AS tablas FROM information_schema.tables WHERE table_schema='zabbix';" 
7. Repositorio e instalación de Zabbix 7.0 — Ubuntu 24.04
wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_7.0-5+ubuntu24.04_all.deb
sudo dpkg -i zabbix-release_7.0-5+ubuntu24.04_all.deb
sudo apt update
sudo apt install zabbix-server-mysql zabbix-frontend-php zabbix-apache-conf zabbix-sql-scripts mariadb-server -y
sudo apt install zabbix-agent2 -y
Servicios del servidor:
sudo systemctl status mariadb
sudo systemctl status apache2
sudo systemctl status zabbix-server
sudo systemctl status zabbix-agent2
